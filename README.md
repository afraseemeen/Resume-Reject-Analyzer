Resume Rejection Analyzer

A Python web application that helps job seekers to identify possible weakness in their resume and improve ATS (Application Tracking System) friendly to achive there desired job.

FEATURES 
1.Upload PDF and DOCX resumes
2.Compare resumes with job descriptions
3.Identify potentially missing skills
4.Suggest resume improvements

TECHNOLOGIES
1.Python
2.Streamlit
3.PyMuPDF
4.Python-docx
5.Scikit-learn
